# JavaScript Blackjack Game

A browser Blackjack game.

## Features

- Start a game, then draw new cards
- Random card values and a running total
- Shows whether you have Blackjack, are still in the game, or are out

## Tech stack

HTML · CSS · vanilla JavaScript

## Running

Open `index.html` in a browser.
